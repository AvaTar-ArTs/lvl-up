# lvl-up 101

The 101 layer is the shortest path from “I know why I want this” to “I have something running.”

Use these guides before the deeper Level 0–5 tracks when a language or layer is new to you.

## Recommended Route

```text
Foundations 101
      ↓
Python 101 — preserve the orchestration brain
      ↓
TypeScript 101 — build product surfaces
      ↓
Rust 101 — add native systems strength
      ↓
C++ / Unreal 101 — enter realtime engines
      ↓
GPU / Shaders 101 — program visual computation
      ↓
Swift 101 — optional native Apple surface
      ↓
Integration 101 — make the layers cooperate
      ↓
Full Tracks → Capstones
```

## How To Use A 101

Do not merely read it. For each guide:

1. install or verify the toolchain;
2. type the first example yourself;
3. change it in one meaningful way;
4. build the mini-project;
5. explain what the language contributes to the stack;
6. move into Level 0 of the full track.

## 60-Minute Rule

A 101 should get you to a working artifact quickly. If you are still collecting tutorials after an hour, stop collecting and build the smallest thing that exercises the concept.

## What Counts As “Ready”

You do **not** need syntax mastery before opening a full track. You are ready when you can:

- run the toolchain without guessing;
- read a small program and roughly explain it;
- change input → logic → output deliberately;
- find and interpret a compiler/runtime error;
- use documentation to answer a question;
- build one tiny useful thing.
